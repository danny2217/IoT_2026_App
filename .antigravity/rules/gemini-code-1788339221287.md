# Android Jetpack Compose & BLE GATT Rules

## 1. BLE Protocol Compliance
- **Write Packets (8 Bytes):**
  - Offset 0-1: Header `0xAA 0x55`
  - Offset 2: `cmdId` (`0x01` START, `0x02` STOP, `0x03` EMERGENCY, `0x05` SET_PERIOD)
  - Offset 3: `mode` (`0x01` Autonomous Strike)
  - Offset 4-5: `periodMs` (uint16 Little-Endian, valid range 200~2000ms)
  - Offset 6: `0x00` (Reserved)
  - Offset 7: XOR Checksum (Bytes 2 to 6)
- **Notify Packets (12 Bytes):**
  - Must parse Little-Endian integers correctly (`chestPressure` at Byte 3-4, `currentPeriod` at Byte 8-9).
  - Map `respirationPhase` (0=None, 1=Inhale, 2=Exhale) directly to UI indicators and lung visualization states.

## 2. Architecture & State Management
- **MVVM Decoupling:** Never trigger BLE Write/Read operations directly from Compose Composable functions. All actions must go through `BleViewModel`.
- **StateFlow Observation:** Expose sensor telemetry, device connection state, and error flags as immutable `StateFlow` from `BleViewModel`. Use `collectAsStateWithLifecycle()` in screens.
- **UI Consistency:** Control panel must not expose intensity controls; it must strictly control strike period (`periodMs`).

## 3. Permissions & Lifecycle
- **Runtime Permissions:** Enforce `BLUETOOTH_SCAN` and `BLUETOOTH_CONNECT` permission requests at runtime (API 31+).
- **Auto-Cleanup:** Ensure GATT connection closes and notification channels unregister when ViewModel is cleared or app process terminates.
